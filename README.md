## 📖 About This Repository

This repository documents my learning journey through **Machine Learning**, as part of my Master's program.

It serves as a structured collection of practical implementations, academic exercises, and projects designed to strengthen my understanding of fundamental Machine Learning concepts and algorithms.

The primary focus is on learning through implementation, experimentation, and problem-solving — developing an understanding of not only how different algorithms work, but also the mathematical principles and computational mechanisms behind them.

The repository is organized into three main sections:

- **Exercises:** Voluntary exercises and presentations implemented in Jupyter Notebooks.
- **Homeworks:** Official course assignments and problem sets.
- **Projects:** Larger practical projects involving Machine Learning concepts, algorithms, and real-world datasets.

## 🧪 1. Exercises

A collection of voluntary exercises prepared for course presentations and supplementary learning activities.

Each exercise is implemented and documented in a **Jupyter Notebook (`.ipynb`)**, providing an interactive environment for explanations, mathematical formulations, coding, and experimentation.

These exercises aim to explore individual Machine Learning concepts in greater depth and provide hands-on experience with different algorithms and techniques.

**Topics may include:**

- 📊 Regression Algorithms
- 🧠 Classification Methods
- 📍 Instance-Based Learning
- 🌳 Decision Trees
- 📈 Model Evaluation and Performance Metrics
- ⚙️ Optimization and Learning Algorithms

## 🚀 3. Projects

This section contains larger practical projects developed as part of the course.

Unlike individual exercises, projects are intended to bring together multiple Machine Learning concepts and techniques to address more comprehensive problems.

Depending on the project, implementations may involve:

- Data preprocessing and exploratory data analysis (EDA).
- Feature engineering and selection.
- Machine Learning model development.
- Model training and evaluation.
- Performance comparison and experimentation.
- Result analysis and visualization.

*Projects will be added as the course progresses.*

## 🎯 Learning Objectives

Through these exercises and projects, the main objectives are to:

1. Develop a solid understanding of fundamental Machine Learning algorithms.
2. Translate mathematical concepts into practical implementations.
3. Understand the internal mechanisms of learning algorithms.
4. Gain experience in data preprocessing, model development, and evaluation.
5. Develop the ability to analyze and compare different approaches.
6. Build a practical foundation for advanced topics in Machine Learning and Artificial Intelligence.
